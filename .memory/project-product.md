**目标**（2026-11-12 主人定）：让用手机通过 UU远程 使用 Mac 的体感最好，往清晰、大、方便做。虚拟屏只是手段。

**形态**（2.0.0 起，到 2.4.2）：
- 手机或平板连上时多出一块竖屏「Snug 手机屏」；不切过去，一切和原版 UU 一样。控制端全是电脑时不加；几台同时连着、其中有手机或平板就加，手机离开也等 15 秒重连窗口（issue #3）
- 屏上是「App 资源库」：在跑的 App 和各自的窗口、本机全部 App、搜索；点窗口放上来铺满、字号放大；底部指示条回到资源库，换窗口时旧窗口归位；断开后全部还原、手机屏移除。右上角可选手机型号、退出手机屏（issue #8）
- Mac 零操作：装好、授一次权限、开机自启；菜单栏只看状态、开设置、退出

**已拍板的取舍**（别走回头路）：
- **不改主屏**：原版「设主屏 + 关物理屏」整套删除，改主屏会让 macOS 重排窗口和菜单栏，把 UU 搅乱
- **默认进手机屏不做**（11-16，issue #9、#11）：UU 每次新连接都从主屏开始，手机屏常驻也进不去（实测见 [[project-phone-screen]]），唯一的办法是设主屏，见上一条。为此提过的「常驻手机屏」开关一并作废
- **一块屏不换方向**：横竖切换要换一块屏，UU 会丢掉选中的屏、跳回第一块，11-13 砍掉（主人：「这里得做减法」）。平板、电脑另加一块固定横屏不算走回头路，见 [[project-tablet-landscape]]
- 键盘遮挡不做：UU 弹键盘时把手机上最后点的位置推到键盘上方，Mac 收不到任何键盘信号；「先点输入行、再弹键盘」就够用
- macOS 自带的缩放无效：UU 抓的是放大前的画面
- **App 资源库**（11-14 拍板，2.3.0）：以 App 为单位增删改查，能打开、新建窗口、退出 App、关单个窗口，不做卸载。点窗口放那个窗口，点 App 放最近用过的，要新窗口点「新建窗口」；「全部」按字典序（中文按拼音），不做「最近使用」；「运行中 / 全部」用分段控件，不用底部标签栏（手机屏底边紧挨 UU 工具栏，容易误点）；放着窗口时它的 App 单列「当前 App」一张卡；退出、关窗都要连按两下。新窗口用「点了才问、问到就停」的 0.1 秒轮询捕获，否掉了 AXObserver 订阅（刚启动的 App 订不上，订上了还得补读一次）
- **在 Snug 之外关窗也要还原**（11-16，issue #14，主人：「能根治多少就多少」，不打补丁）：账不随窗口销，转成留下的账，窗口带着手机屏的尺寸回来时再还（只认看得见的证据，尺寸对不上就不碰）；手机上点窗口的关闭按钮要先放回再关；⌘W 不拦，在 VS Code 里它是关标签页。剩下 VS Code、Cursor 用快捷键或菜单关窗、远程结束后再开时字号偏大，认不出来，只能在关窗当时提示
- 列表交互：放着窗口时左上角显示「‹ App 名」返回键，没有就不显示；打开窗口时整屏显示「正在打开」；列表露着时卡片不换位置
- **屏幕适配**（11-14 拍板，2.2.0）：App 限定了最小尺寸时，手机屏换成刚好装得下的一档（等比、最宽 1080），窗口照样铺满、字跟着小，手机上双指放大。按窗口实测选档、不按 App 预设；不做左右平移。主人看过 740 那档「有点偏小」，仍选这条：通用、不用一个个填坑
- **手机型号定比例**（11-15 拍板，2.4.0）：按用户选的型号算比例。机型库是单一数据源 `Assets/phone-models.json`（主人强调过多次：数据不许散开，加机型只改它）；列表里没有的可自己填分辨率或比例。入口两处：Mac 设置和手机屏资源库右上角（手机上选完当场看到效果）。换型号在线换比例、不撤屏。UU 读不到手机分辨率（日志加密），控制端名字里也没有具体型号，没法自动识别。机型数据以官网为准、规格站补；搜集时别让 agent 开浏览器在官网 JS 页面上耗（11-15 第一轮卡了一个多小时被掐），只用搜索和抓网页，一款试两次不成就跳过

**边界**（11-15 主人定 issue #4，11-16 因 issue #10 改）：原先只做「手机、平板远程 Mac」，电脑控制端不管。现在改成「给每种控制端一块合身的屏」：电脑和平板共用一块横屏，等 iPad 到了一起做，详见 [[project-tablet-landscape]]。改的原因：UUyc-companion 10-13 起停更，#10 报告人说它在系统更新后已失效，「不重复造轮子」不再成立；平板反正要做横屏，电脑是第二个用例。仍然不做 UUyc 的「设主屏 + 关物理屏」，横屏是扩展出来的一块。#4 已关，功能发布后可以回去补一句

**How to apply:** 设计任何交互先问三件事：只用手机能不能完成？没用手机屏时是不是和原版 UU 一样？改动是不是只限 Snug 自己的屏、并且能还原？协作偏好见 [[feedback-product-thinking]]，实现上的坑见 [[project-phone-screen]]，回复 issue 见 [[feedback-issue-replies]]
